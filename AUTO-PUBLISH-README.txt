HD GRASS + LGPE FLOWERS - SEAMLESS GITHUB UPDATE

This repo keeps the original HD Grass mod ID so installed v3.4.0 copies can auto-update to the combined v3.4.1 release.

FIRST COMBINED PUBLISH:
1. Extract this repo ZIP.
2. Double-click PUBLISH_UPDATE.bat.
3. It attaches to randyadr/Gen1-Recomp-HD-Grass if needed.
4. It publishes v3.4.1 with asset:
   DRAMATIC_SHAPE_GRASS_OBJ_REPLACER_V3-3.4.1.zip

LATER UPDATES:
Run PUBLISH_UPDATE.bat again. Once v3.4.1 exists, it bumps to v3.4.2, then v3.4.3, etc.
