# HD Grass + LGPE Wind Flowers

This is the existing HD Grass V3 mod, upgraded to include the LGPE 3D flower replacement in the same renderer chain.

- optimized custom 3D grass
- corrected LGPE flower model/texture replacement
- 60 Hz wind sway for grass and flowers
- Dramaless Shape / Dramatic Shape compatible

Because the mod keeps the original `DRAMATIC_SHAPE_GRASS_OBJ_REPLACER_V3` ID, existing HD Grass installations can update directly instead of installing a second mod.
