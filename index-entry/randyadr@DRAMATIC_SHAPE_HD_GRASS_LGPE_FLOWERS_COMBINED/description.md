# HD Grass + LGPE Wind Flowers

Combines the custom HD grass replacement and LGPE 3D flower replacement into one renderer chain for **Dramaless Shape** or **Dramatic Shape**.

## Features

- Replaces upright voxel grass with the optimized custom 3D grass model.
- Replaces native voxel flowers with the LGPE 3D flower model and corrected flower texture mapping.
- Adds 60 Hz wind sway to both grass and flowers.
- Keeps the grass chunking/culling optimizations from the standalone HD Grass build.
- Uses one composed renderer chain so the standalone grass and flower wrappers do not fight each other.

## Install

Import the release ZIP in Gen1Recomp and enable this mod with Dramaless Shape or Dramatic Shape. Disable the old standalone HD Grass and standalone flower replacer mods while using this combined build.

## Compatibility

The combined mod can still be used with the separate Tree and HGSS Building replacement mods.
